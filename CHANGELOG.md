### Changed
- Faster page transitions and loads. The Navigator renders each stack entry through a memoised host and keeps the stack in a store: a push, back or toast no longer re-renders the screens underneath, and `useNav()` re-renders a component on navigation only when its render reads `stack` / `canGoBack` / `isRoot` (handlers still get the live stack). PLP, PDP, checkout, search, noon One landing and the address map use `useIsTop()`; PLP cards are memoised; `SkeletonReveal` unmounts its skeleton once faded. Membership screens load lazily like every other flow; `Icon` imports lucide icons by name (no namespace import), so the entry chunk drops ~20 KB gzipped. Measured on PLP → PDP in dev: main-thread block per warm push ~245 → ~130 ms, back ~100 → ~55 ms.
- Dev preview: no React StrictMode by default (it rendered every screen twice); `VITE_STRICT=1 npm run dev` turns it back on. The Lottie player wasm is served by the app instead of the jsdelivr CDN.
